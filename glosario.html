30+ key terms in technology, cybersecurity and digital design. Bilingual reference: English & Español.

English Term Español Definition / Definición
Artificial Intelligence (AI) Inteligencia Artificial (IA) Simulation of human intelligence processes by machines, including learning, reasoning, and self-correction. / Simulación de procesos de inteligencia humana por máquinas, incluyendo aprendizaje, razonamiento y autocorrección.
Machine Learning Aprendizaje Automático A subset of AI that enables systems to learn and improve from experience without being explicitly programmed. / Subconjunto de IA que permite a los sistemas aprender y mejorar a partir de la experiencia sin ser explícitamente programados.
Cybersecurity Ciberseguridad Practice of protecting systems, networks, and programs from digital attacks, theft, and damage. / Práctica de proteger sistemas, redes y programas de ataques digitales, robo y daños.
Ransomware Secuestro de datos Malicious software that encrypts a victim's files and demands payment for the decryption key. / Software malicioso que cifra los archivos de la víctima y exige un pago por la clave de descifrado.
Phishing Suplantación de identidad Fraudulent attempt to obtain sensitive information by disguising as a trustworthy entity. / Intento fraudulento de obtener información sensible disfrazándose de una entidad de confianza.
Zero Trust Confianza Cero Security model that requires strict identity verification for every person and device trying to access resources. / Modelo de seguridad que requiere verificación estricta de identidad para cada persona y dispositivo que intenta acceder a recursos.
Encryption Cifrado Process of encoding information so only authorized parties can access it. / Proceso de codificación de información para que solo las partes autorizadas puedan acceder a ella.
Firewall Cortafuegos Network security device that monitors and controls incoming and outgoing network traffic. / Dispositivo de seguridad de red que monitorea y controla el tráfico de red entrante y saliente.
Penetration Testing Prueba de Penetración Authorized simulated cyberattack performed to evaluate the security of a system. / Ataque cibernético simulado y autorizado para evaluar la seguridad de un sistema.
User Experience (UX) Experiencia de Usuario Overall experience a user has when interacting with a product, especially in terms of how easy or pleasing it is to use. / Experiencia general que tiene un usuario al interactuar con un producto, especialmente en términos de facilidad y satisfacción.
User Interface (UI) Interfaz de Usuario The visual and interactive elements that allow users to interact with a software application. / Elementos visuales e interactivos que permiten a los usuarios interactuar con una aplicación de software.
Responsive Design Diseño Responsivo Design approach ensuring web pages render well on a variety of devices and window or screen sizes. / Enfoque de diseño que garantiza que las páginas web se visualicen bien en una variedad de dispositivos y tamaños de pantalla.
Accessibility Accesibilidad Design of products and services usable by people with disabilities, ensuring equal access and opportunity. / Diseño de productos y servicios utilizables por personas con discapacidades, garantizando igualdad de acceso y oportunidad.
Design System Sistema de Diseño Collection of reusable components, guided by clear standards, that can be assembled to build any number of applications. / Colección de componentes reutilizables, guiados por estándares claros, para construir aplicaciones.
Wireframe Esquema de Interfaz A low-fidelity visual guide representing the skeletal framework of a website or application. / Guía visual de baja fidelidad que representa el esqueleto de un sitio web o aplicación.
Prototype Prototipo Early model of a product built to test concepts or processes before final production. / Modelo temprano de un producto construido para probar conceptos o procesos antes de la producción final.
Digital Transformation Transformación Digital Integration of digital technology into all areas of a business, changing how it operates and delivers value. / Integración de tecnología digital en todas las áreas de un negocio, cambiando cómo opera y entrega valor.
Cloud Computing Computación en la Nube Delivery of computing services over the internet including storage, processing, and networking. / Entrega de servicios informáticos a través de internet, incluyendo almacenamiento, procesamiento y redes.
Internet of Things (IoT) Internet de las Cosas Network of physical devices embedded with sensors and software that connect and exchange data. / Red de dispositivos físicos integrados con sensores y software que se conectan e intercambian datos.
Blockchain Cadena de Bloques Decentralized digital ledger that records transactions across a network of computers in a tamper-resistant manner. / Libro de contabilidad digital descentralizado que registra transacciones de forma resistente a manipulaciones.
API (Application Programming Interface) Interfaz de Programación de Aplicaciones A set of rules that allows different software applications to communicate with each other. / Conjunto de reglas que permite a diferentes aplicaciones de software comunicarse entre sí.
DevOps Desarrollo y Operaciones Practices combining software development and IT operations to shorten the development lifecycle. / Prácticas que combinan desarrollo de software y operaciones de TI para acortar el ciclo de vida del desarrollo.
Agile Methodology Metodología Ágil Iterative approach to software delivery that builds software incrementally from the start of the project. / Enfoque iterativo para la entrega de software que construye de forma incremental desde el inicio del proyecto.
Data Analytics Análisis de Datos Science of analyzing raw data to find trends and answer questions to make informed decisions. / Ciencia de analizar datos brutos para encontrar tendencias y responder preguntas para tomar decisiones informadas.
Big Data Macrodatos Extremely large datasets that may be analyzed computationally to reveal patterns, trends, and associations. / Conjuntos de datos extremadamente grandes que pueden analizarse computacionalmente para revelar patrones y tendencias.
Neural Network Red Neuronal Computing system inspired by biological neural networks, used to recognize patterns and learn from data. / Sistema informático inspirado en redes neuronales biológicas, utilizado para reconocer patrones y aprender de datos.
Deep Learning Aprendizaje Profundo Subset of machine learning using multilayered neural networks to learn representations from large amounts of data. / Subconjunto del aprendizaje automático que usa redes neuronales multicapa para aprender representaciones de grandes cantidades de datos.
Automation Automatización Use of technology to perform tasks with minimal human intervention, increasing efficiency and consistency. / Uso de tecnología para realizar tareas con mínima intervención humana, aumentando la eficiencia y consistencia.
Dark Pattern Patrón Oscuro de Diseño Deceptive UI/UX design technique that tricks users into doing things they did not intend to. / Técnica de diseño UI/UX engañosa que manipula a los usuarios para que hagan cosas que no pretendían.
Scrum Scrum Agile framework for developing, delivering, and sustaining products in complex environments using short sprints. / Marco ágil para desarrollar, entregar y mantener productos en entornos complejos usando sprints cortos.
Microservices Microservicios Architectural style that structures an application as a collection of loosely coupled, independently deployable services. / Estilo arquitectónico que estructura una aplicación como una colección de servicios débilmente acoplados e independientemente desplegables.
Multi-Factor Authentication (MFA) Autenticación Multifactor Security mechanism requiring users to provide two or more verification factors to gain access to a resource. / Mecanismo de seguridad que requiere que los usuarios proporcionen dos o más factores de verificación para acceder a un recurso.
Open Source Código Abierto Software whose source code is freely available for anyone to use, modify, and distribute. / Software cuyo código fuente está disponible libremente para que cualquiera lo use, modifique y distribuya.
